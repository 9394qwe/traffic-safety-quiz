# 交通安全答题挑战

97道题，每人随机5题，每题20秒，答后立即显示正确答案。五题全对显示礼品庆祝画面。背景音乐与音效可分别关闭。

## GitHub Pages 发布

1. 创建用于本程序的公开仓库（免费账号）。注意：题库、答案和程序均会公开。
2. 将本文件夹中的 index.html、sw.js、manifest.webmanifest、icon.png、.nojekyll 上传到仓库根目录。
3. 仓库 Settings → Pages → Deploy from a branch → main → /(root) → Save。
4. 等待发布成功后，用 Pages 设置页显示的实际网址访问；不要把仓库文件页面当作答题网址。
5. 先让同事在不使用VPN的国内网络中测试网址是否可达；不能保证所有地区和运营商网络都稳定可达。

## 离线准备

首次联网打开，等显示“离线已就绪”。iPad用Safari添加到主屏幕，再从主屏幕联网打开一次；开启飞行模式并关闭Wi-Fi，关闭后重新打开并试答一组。

## 更新注意

改题库或程序后，将 sw.js 与 index.html 中的 traffic-github-v1 同时改为新的版本号，再上传更新。请在活动前联网打开并确认新版本，避免活动中切换版本。请继续保留单文件离线版作为备用。
